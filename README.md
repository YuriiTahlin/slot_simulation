# Slot Machine Simulator

Цей проєкт є **симулятором слот-машини**, який використовує три барабани для генерації виграшних комбінацій. Він дозволяє моделювати й аналізувати ігрові обертання, виграші та статистику на основі заданих параметрів.

## Особливості:
- **Генерація випадкових символів** для барабанів.
- **Обчислення RTP** (Return to Player).
- **Розрахунок волатильності** та **частоти виграшів**.
- **Детальна статистика виграшів** за комбінаціями.

## Версія:
- **v2.0.1**: Оновлена версія з підтримкою детальної статистики виграшів за комбінаціями, додані невеликі зміни.

## Як запустити:

### 1. Створіть нове віртуальне середовище (наприклад у PyCharm або через термінал): python -m venv venv .

### 2. Активуйте середовище:
- Для **Windows**: venv\Scripts\activate .
- Для **macOS/Linux**: source venv/bin/activate .

### 3. Встановіть залежності:
Використовуйте файл `requirements.txt`, щоб встановити всі необхідні бібліотеки: pip install -r requirements.txt .
