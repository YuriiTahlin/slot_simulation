Цей проект є симулятором слот-машини, який використовує три барабани для генерації виграшних комбінацій. Він дозволяє моделювати й аналізувати ігрові обертання, виграші та статистику на основі заданих параметрів.

## Особливості:
- Генерація випадкових символів для барабанів.
- Обчислення RTP (Return to Player).
- Розрахунок волатильності та частоти виграшів.

## Версія:
- **v2.0**: Оновлена версія з підтримкою детальної статистики виграшів за комбінаціями.
